# Marimay application examples

A local collection of independent learning projects from the
[Marimay](https://github.com/marimay-lang/marimay) ecosystem. Each application
has its own repository, source, tests and process-acceptance scripts.

| Project | Purpose |
|---|---|
| [marimay-config](https://github.com/marimay-lang/marimay-config) | Validate and migrate scanner configuration |
| [route-planner](https://github.com/marimay-lang/route-planner) | Shortest-path graph example |
| [marimay-notes](https://github.com/marimay-lang/marimay-notes) | Local notes with typed JSON persistence |
| [marimay-grep](https://github.com/marimay-lang/marimay-grep) | Literal streaming line search |
| [marimay-frequency](https://github.com/marimay-lang/marimay-frequency) | Unique lines and stable frequency counts |
| [marimay-logstats](https://github.com/marimay-lang/marimay-logstats) | Structured log summaries |
| [marimay-manifest](https://github.com/marimay-lang/marimay-manifest) | Directory metadata inventories |
| [marimay-project-check](https://github.com/marimay-lang/marimay-project-check) | Configured file-policy checks |
| [marimay-env-paths](https://github.com/marimay-lang/marimay-env-paths) | Explicit environment and path reports |
| [marimay-delimited](https://github.com/marimay-lang/marimay-delimited) | Bounded CSV/TSV and JSON conversion |
| [marimay-source-lint](https://github.com/marimay-lang/marimay-source-lint) | Six lexical source checks |

These are open-source MIT personal learning and hobby experiments. Existing
verification notes describe local historical runs; full platform, ergonomics
and performance acceptance remains in progress. Each README documents its
commands and limits. `.acceptance-data/` and `.measure-data/` are generated
test trees, excluded from publication.
